# Dig’em Aggies

Repository for the official website of **Dig’em Aggies**, a student organization at **Texas A&M University** dedicated to design, development, and outreach in tunnel boring technology.

## 🌐 Overview

This website serves as the public-facing platform for the Dig’em Aggies team.  
It highlights our mission, sponsors, projects, outreach initiatives, and recruitment opportunities.

Built with:
- HTML, CSS, and JavaScript (no frameworks)
- Responsive layout for desktop and mobile
- Interactive sponsor animations and tiered recognition system
